Migracao para Supabase

Esta pagina envia uma copia dos dados locais deste navegador para o banco online. Ela nao apaga localStorage nem IndexedDB e exige login pelo Supabase Auth.

1. Execute supabase/schema.sql no Supabase.
2. Preencha js/supabase-config.js com Project URL e Publishable Key.
3. Abra esta pagina no mesmo navegador onde os dados locais estao salvos.
Aguardando inicio da migracao.
