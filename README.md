# Controle de Processos - Versao 3.0

Sistema web estatico para controle de processos, trâmites, fornecedores, contratações e atas de registro de preço.

## Publicacao

O projeto pode ser publicado no GitHub Pages porque usa HTML, CSS e JavaScript puro.

Arquivo inicial:

- `index.html`

## Supabase

A preparacao inicial da migracao para armazenamento online esta nestes arquivos:

- `supabase/schema.sql`
- `js/supabase-config.js`
- `js/database.js`
- `js/migracao-supabase.js`
- `migracao-supabase.html`
- `MIGRACAO-SUPABASE.md`

Leia `MIGRACAO-SUPABASE.md` antes de executar a migracao.
